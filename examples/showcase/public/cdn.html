Holotope from a CDN

No build step, no bundler, no install. This page loads the published packages straight from jsDelivr and checks itself. 

import * as THREE from 'https://cdn.jsdelivr.net/npm/three@0.185.1/+esm';
import { createHypercube, cuboidCellFacetN } from 'https://cdn.jsdelivr.net/npm/@holotope/core@0.0.22/+esm';
import { SlicedComplex3D } from 'https://cdn.jsdelivr.net/npm/@holotope/three@0.0.22/+esm';

The +esm suffix matters. Without it the adapter packages still download, but they import the bare specifier '@holotope/core', which a browser cannot resolve. +esm rewrites those to exact pinned versions.

The three version above is pinned to the one jsDelivr resolves @holotope/three against. That is what keeps a single Three.js instance in the page: two copies would still render, but instanceof across them fails, and the checks below would catch it.
